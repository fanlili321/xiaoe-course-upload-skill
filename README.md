# xiaoe-course-upload

把飞书文档里写好的图文课程，新建成小鹅通后台（螺丝钉学院店铺）里的一门图文课程。这是一个供 Claude Code 使用的 skill。

## 这个 skill 做什么

使用者只需要提供**飞书文档链接**和**课程名**，中间确认一次，Claude 会自动完成：

1. 读飞书文档，按一级标题（`# `）拆成小节，下载全部图片；列出文档评论和"发布前删除 / 待改"等草稿标记，请你决定怎么处理。
2. 生成封面（可选），整理上传文件。
3. 给你确认一次方案：课程名、小节列表、图片、上架状态。
4. 在小鹅通新建课程（免费、**暂不上架**），上传图片，选好封面，并逐个新建图文小节。
5. 回读每个小节，和飞书原文逐字核对标题、正文、图片、表格，然后汇报。

## 安全设计

- **只新建、不删除**：脚本里没有任何删除操作。更新旧课只在你明确要求时才做，而且会先备份。
- **同名不覆盖**：已有同名课程会直接停下；已有同名小节会跳过。中途失败后重跑，既不会重复建小节，也不会重复上传图片。
- **新课默认"暂不上架"**：保存前会再核对一次名称、免费、暂不上架和封面，任一项不对就不保存。
- **禁止点击清单**：删除、批量操作、上架/下架、去开启、充值等按钮一律不点，详见 SKILL.md。
- **出错即停**：任何一步报错都会停下来，不会绕路硬做。

## 安装

1. 点 GitHub 页面的 **Code → Download ZIP**，或用链接 `https://github.com/fanlili321/xiaoe-course-upload-skill/archive/refs/heads/main.zip` 下载。
2. 解压后，把包含 `SKILL.md` 的文件夹改名为 `xiaoe-course-upload`，放到 `~/.claude/skills/` 下。

## 使用前提

- 已安装并登录 `lark-cli`（`--as user`），用来读飞书文档和下载图片。
- 已安装 Tabbit 浏览器，并在里面登录小鹅通后台 `admin.xiaoe-tech.com`。
- 有 Python 3 和 Pillow；建议安装思源黑体（`SourceHanSansCN`），生成封面、改图时会用到。
- 本 skill 是按小鹅通后台 2026 年 11 月的页面写的。后台改版后，页面元素的定位可能需要调整，参见 `references/xiaoe-ui.md`。

## 用法示例

> 把这个飞书文档传到小鹅通，新建一门课，课程名叫《私募第一课》：https://xxx.feishu.cn/wiki/xxxx

## 文件结构

```
SKILL.md                     全流程、安全底线、禁止点击清单
references/xiaoe-ui.md       小鹅通后台页面定位、悬停菜单、UEditor 读写、备份、改标题等代码
scripts/
  prepare.sh                 一键：读飞书文档 → 拆小节 → 下载图片（只读）
  feishu_to_sections.py      飞书 markdown → 小节 HTML，列出评论和草稿标记
  make_cover.py              生成 750×422 课程封面
  prepare_upload.py          统一命名要上传的图片（支持替换改好的图）
  make_course_js.py          生成建课脚本（同名检查、上传图片、选封面）和保存脚本（保存前再核对一次）
  build_final.py             把图片占位换成素材库地址，可选去掉"第X课"
  make_tabbit_js.py          生成每个小节的新建脚本（防重复）和回读脚本
  run_sections.sh            按顺序新建全部小节，出错即停
  compare.py                 回读结果与原文逐字核对
  read_resource.py           取回 Tabbit 较大的返回结果
```
